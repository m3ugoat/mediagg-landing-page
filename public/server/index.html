Mediagg Server · macOS and Linux

A home media server, set up for you.

Mediagg Server turns a Mac, a Raspberry Pi or a Linux computer into a home media server. One command installs the services you choose, sets each one up and connects them to each other.

curl -fsSL https://mediagg.app/install.sh | sh

Paste it into a terminal, on the computer itself or over SSH. It runs in Docker and installs Docker if it is missing. To remove it: curl -fsSL https://mediagg.app/install.sh | sh -s -- --uninstall

1

Run the command

Choose the drive or folder it may use. It only ever sees that one.

2

Answer a few questions

In your browser: what you watch and listen to, whether it should find more, and your account.

3

Press Install

Each service is installed, set up and connected to the others.

4

Open Mediagg

Stream in Mediagg Web App on the server's Home opens Mediagg, signed in to everything. In the phone or TV app, add each server by its address.

Mediagg in the browser, built in

Every service, already signed in.

Your Mediagg Server serves Mediagg itself. Open it with Stream in Mediagg Web App on the server's Home: what the server set up is there and signed in, and podcasts and pictures a browser blocks come through the server. This is the one way to host Mediagg in the browser yourself.

Before you start

A Mac, or a Linux computer such as a Raspberry Pi, that stays switched on. Running the command again updates it to the newest version and keeps everything.
