Made for the remote.

About Mediagg Server
Mediagg Server · macOS and Linux

No server yet? Mediagg Server sets one up.

A Mac, a Raspberry Pi or a Linux computer becomes a home media server: Jellyfin, Navidrome, Audiobookshelf and the services that find more, each set up and connected for you.

curl -fsSL https://mediagg.app/install.sh | sh
How Mediagg Server works

Chromecast and DLNA

Cast to Chromecast and to DLNA/UPnP players, including files on your phone.

One search

Your device, your podcasts and every server at once. Discover searches podcast directories.

Downloads

Keep albums, films and episodes on the phone for when there is no connection.

Station playlists

Radio and TV stations from m3u playlists, kept up to date, from a public directory or an m3ugoat server.
