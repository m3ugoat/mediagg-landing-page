m3ugoat

A playlist server you run yourself — and one of the places Mediagg can subscribe to.

m3ugoat is a small program you run on your own network, on a computer or a home server. It keeps your IPTV playlists in one place: you add channels to it, put them in the order you want, hide the ones you never watch, and group them into playlists.

Mediagg then signs in to it and reads those playlists directly, so what you subscribe to on your phone is what you arranged on the server — including the ordering and the hidden channels.

It is not a service, and there is nothing to sign up to. Nobody runs m3ugoat for you. If you are not already running one, there is nothing to add in the app yet — start with the server, then come back.

Why not just paste a playlist link?

You can. m3ugoat gives every playlist a plain export link, and any IPTV player will take it — that is exactly what it is for.

Mediagg does something different on purpose. It talks to the server's API rather than downloading the finished file, because a plain m3u file has nowhere to record two of the decisions you made: which channels are hidden, and what order they go in. Reading the API keeps both.

There is a second reason. An export link can be rotated — you regenerate it when a link has been shared too widely. A subscription pinned to that link would quietly fork into a second copy the day you pressed the button. Signing in avoids that entirely.

Adding your server to Mediagg

  1. In Mediagg, open Subscriptions and choose m3ugoat from the list of providers.
  2. Tap Add an m3ugoat server and enter its address — usually a local one, like 192.168.1.10:8080.
  3. Sign in if the server asks. A server with no accounts on it needs no password, and Mediagg checks which case it is before offering the fields. A username is only needed once the server has more than one account.
  4. Open the server to see its playlists, and subscribe to the ones you want. Your m3ugoat categories come through as the group each channel sits in.

Signing in adds that phone to the server's own device list, where you can sign it out again later — useful if you lose the device or simply stop using it.

You can add more than one server. The provider lists every server you have added, and opening one shows that account's playlists.

Getting m3ugoat

m3ugoat is free and open source, under the GPL-3.0 licence. It is a fork of m3u4me by Andrei Savin, which is the same idea without the multi-user accounts and the sync API that Mediagg uses.

github.com/m3ugoat/m3ugoat — installation is a git clone, npm install, npm run build, and PM2 to keep it running. It needs Node 24 or newer.

A note on what it does not do

m3ugoat provides no channels and no streams. It is a manager for playlists you already have, exactly as Mediagg is a player for media you already have. You bring your own content.
