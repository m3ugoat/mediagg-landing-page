m3ugoat

A self-hosted IPTV playlist manager that Mediagg can subscribe to.

m3ugoat is a server you run on your own network, on a computer or a home server. It stores your IPTV playlists in one place, where you can add channels, set their order, hide channels and group them into playlists.

Mediagg connects to m3ugoat through its API and reads your playlists directly, so your subscriptions in the app match what you set up on the server, including channel order and hidden channels.

m3ugoat is self-hosted. There is no account to create and no hosted version. To use it with Mediagg, set up an m3ugoat server first, then add it in the app.

Why Mediagg uses the API instead of a playlist link

m3ugoat provides a standard export link for every playlist, which any IPTV player can use.

Mediagg reads the server's API instead of the exported file, because an m3u file does not record which channels are hidden or the order you set. The API includes both.

Export links can also be regenerated, for example when a link has been shared too widely. A subscription tied to the old link would stop matching the server. Signing in avoids this.

Adding your server to Mediagg

  1. In Mediagg, open Subscriptions, tap +, choose Add from providers, then m3ugoat.
  2. Tap Add an m3ugoat server and enter its address, usually a local one such as 192.168.1.10:8080.
  3. Sign in if the server requires it. A server with no accounts does not need a password; Mediagg checks this before showing the sign-in fields. A username is only required when the server has more than one account.
  4. Open the server to see its playlists, and subscribe to the ones you want. Your m3ugoat categories are used as the channel groups.

Signing in adds the device to the server's device list, where you can sign it out later, for example if the device is lost or no longer used.

You can add more than one server. The provider lists every server you have added, and opening one shows that account's playlists.

Getting m3ugoat

m3ugoat is free and open source.

github.com/m3ugoat/m3ugoat-playlist-manager. Installation uses git clone, npm install and npm run build, with PM2 to keep the server running. It requires Node 24 or newer.

What m3ugoat does not include

m3ugoat does not provide channels or streams. It manages playlists you already have, in the same way that Mediagg plays media you already have.
