Documentation/Media servers

Media servers

Signing in to Jellyfin, Subsonic, Plex, Emby or Audiobookshelf, and browsing what is on them.

If you run a media server at home, Mediagg is a client for it. Your library stays on the server — Mediagg signs in, browses it live, plays from it and reports back where you got to, so the server and your other players stay in step.

Five kinds of server are supported, and you can add more than one of each.
