No server of your own yet? These public demo servers are run by the projects behind the server
software, and each one signs in with the same `Address`, `Username` and `Password` form as your own
would — see [Adding a server](/documentation/media-servers/add-a-server).

Pick the kind in `Choose a provider`, then copy the details below.

## Navidrome — choose `Subsonic`

Navidrome speaks the Subsonic protocol, so it is added as `Subsonic`.

```
Address:  https://demo.navidrome.org
Username: demo
Password: demo
```

## Jellyfin — choose `Jellyfin`

**The password is empty** — leave the field blank rather than typing anything into it.

```
Address:  https://demo.jellyfin.org/stable
Username: demo
Password: (leave blank)
```

Jellyfin runs a second demo on its development version, with the same sign-in:

```
Address:  https://demo.jellyfin.org/unstable
Username: demo
Password: (leave blank)
```

## Audiobookshelf — choose `Audiobookshelf`

```
Address:  https://audiobooks.dev
Username: demo
Password: demo
```

## Before you get attached

- **Everyone shares these accounts, and the servers are reset regularly.** Favourites, playlists
  and where you got to in a book can be changed by somebody else or disappear overnight.
- **Emby and Plex have no public demo.** Signing in to Plex goes through a plex.tv account, so both
  need a server of your own.
- When you are done, `Forget this server` in `Manage servers` removes it — see
  [Adding a server](/documentation/media-servers/add-a-server#more-than-one).
